# Third-party code, data and assets

BRIDGE LAB uses the following third-party code, data and services.

| What | Used for | License (published) |
|---|---|---|
| Meta Model API, `muse-spark-1.3` | All model calls in the pipeline | Meta developer terms |
| RDKit | Fingerprints, structure comparison, `structure_cell_knn` | BSD-3-Clause |
| NumPy | Bootstrap and the structure method | BSD-3-Clause |
| 3Dmol.js (minified copy inside `demo-ui/index.html`) | Interactive 3D structure viewer | BSD-3-Clause |
| Cormorant Garamond, DM Mono, Outfit (loaded from Google Fonts at runtime) | Page typography | SIL Open Font License 1.1 |
| NCI-ALMANAC drug-combination screen | Training data and candidates (`comparison-prereg-v4/`) | Public data from the NCI Developmental Therapeutics Program (Holbeck et al., Cancer Research 2017) |
| NCI/CADD Chemical Identifier Resolver, PubChem | Structure lookup (SMILES, SDF) | Public services; cited in the Evidence tab |
